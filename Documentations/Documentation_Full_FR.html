Bibliothèque PowerShell Tween

Un moteur d'animation et de tweening léger, orienté objet (classes), conçu pour Windows Forms en PowerShell. Implémente l'ensemble des équations d'atténuation de Robert Penner pour des transitions fluides et dynamiques sous Windows.

"And yes, it's quite useless but it's funny :)"

✨ Fonctionnalités

  • 41 Courbes d'Atténuation de Robert Penner : Intègre toutes les familles classiques (Linear, Quad, Cubic, Quart, Quint, Sine, Expo, Circ, Elastic, Bounce, Back) déclinées selon les modes In, Out, InOut et OutIn.
  • Pur PowerShell 5.1+ Orienté Objet : Implémenté nativement avec les classes PowerShell pour des performances optimales et un code propre et modulaire.
  • Zéro Dépendance Binaire Externe : Fonctionne directement avec les composants standards .NET System.Windows.Forms et System.Drawing.
  • Animation Complète des Contrôles : Anime positions (Point), couleurs ARGB (ForeColor / BackColor), compteurs textuels numériques, barres de progression et opacité de fenêtres.
  • Architecture Événementielle & Séquences : Support des délais de départ, pause/reprise, finalisation forcée et callbacks avec transmission d'arguments personnalisés.
  • Cycle de Vie Automatique : Chaque instance de tween s'enregistre automatiquement dans la boucle moteur active et se désinscrit d'elle-même dès achèvement.

🏛 Architecture du Projet

Le projet est structuré de manière modulaire au sein du répertoire Tweens/ :

Fichier Rôle Responsabilités Principales
TweensVariables.ps1 Constantes Déclare les 41 identifiants d'easing dans le scope $Script (ex: $Script:easeBounceOut).
Tweens.ps1 Modèles de Données Définit la classe de base Tween et l'ensemble des modèles d'animation dérivés.
TweensUpdater.ps1 Moteur & Timer Gère le Timer central, la liste $Script:tweensList et la boucle de rendu par frame.
TweensMovement.ps1 Mathématiques & Logique Calcule les interpolations via la fonction Ease et applique les mutations de propriétés.

🚀 Guide de Démarrage

Prérequis

Windows PowerShell 5.1 ou PowerShell 7+ sous Windows avec les bibliothèques WinForms chargées.

Importation des Modules (Dot-Sourcing)

POWERSHELL 
# Chargement des bibliothèques WinForms
Add-Type -AssemblyName System.Windows.Forms
Add-Type -AssemblyName System.Drawing

# Importation dans l'ordre
. "$PSScriptRoot\Tweens\TweensVariables.ps1"
. "$PSScriptRoot\Tweens\Tweens.ps1"
. "$PSScriptRoot\Tweens\TweensUpdater.ps1"
. "$PSScriptRoot\Tweens\TweensMovement.ps1"

Gestion du Cycle de Vie du Moteur

POWERSHELL 
# 1. Démarrer la boucle d'animation à l'affichage du formulaire
$mainForm.Add_Shown({ 
    $Script:tweensTimer.Start()
})

# 2. CRITIQUE : Arrêter et libérer (Dispose) le Timer à la fermeture
$mainForm.Add_Closing({ 
    $Script:tweensTimer.Stop()
    $Script:tweensTimer.Dispose() 
})
💡
Personnalisation de la fréquence d'images (FPS) La cadence par défaut est fixée à 60 FPS ($Script:refreshRate = 60 dans TweensUpdater.ps1). Vous pouvez modifier cette valeur avant de démarrer le minuteur.

Exemple Minimal Exécutable

POWERSHELL (Script Complet) 
Add-Type -AssemblyName System.Windows.Forms
Add-Type -AssemblyName System.Drawing

. "$PSScriptRoot\Tweens\TweensVariables.ps1"
. "$PSScriptRoot\Tweens\Tweens.ps1"
. "$PSScriptRoot\Tweens\TweensUpdater.ps1"
. "$PSScriptRoot\Tweens\TweensMovement.ps1"

$form = [System.Windows.Forms.Form]::new()
$form.Text = "Exemple Minimal Tween"
$form.Size = [System.Drawing.Size]::new(400, 300)
$form.StartPosition = "CenterScreen"

$btn = [System.Windows.Forms.Button]::new()
$btn.Text = "Cliquez-moi !"
$btn.Size = [System.Drawing.Size]::new(130, 40)
$btn.Location = [System.Drawing.Point]::new(20, 20)
$form.Controls.Add($btn)

$btn.Add_Click({
    $dest = [System.Drawing.Point]::new(220, 180)
    $t = [TweenMoveTo]::new($btn, $dest, 1.5, $Script:easeBounceOut)
    $t.setOnComplete({ $btn.Text = "Arrivé !" })
})

$form.Add_Shown({ $Script:tweensTimer.Start() })
$form.Add_Closing({
    $Script:tweensTimer.Stop()
    $Script:tweensTimer.Dispose()
})

[System.Windows.Forms.Application]::Run($form)

📚 Référence des Classes de Tween

Classe de Base : Tween

La classe mère abstraite de toutes les animations. Toute instanciation s'inscrit automatiquement dans $Script:tweensList.

Méthode Signature Description
setDelay [void] setDelay([double]$secondes) Définit un délai en secondes avant le démarrage.
setOnComplete [void] setOnComplete([scriptblock]$cb) Enregistre un callback exécuté dès l'achèvement.
setOnComplete [void] setOnComplete([scriptblock]$cb, [object[]]$args) Enregistre un callback avec transmission d'arguments.
pause [void] pause([bool]$estEnPause) Met en pause ($true) ou reprend ($false) l'animation.
stop [void] stop() Annule et retire immédiatement le tween de la boucle.
forceEnd [void] forceEnd() Annule le délai restant et force la fin au prochain tick.

1. TweenMoveTo

Anime les coordonnées 2D Location (Point(X, Y)) d'un contrôle Windows Forms.

CONSTRUCTEUR & EXEMPLE
[TweenMoveTo]::new([Control]$pControl, [System.Drawing.Point]$pDestPos, [double]$pDuration, [string]$pEasing)

# Exemple : Déplacer un bouton vers (350, 120) en 1.2s
$cible = [System.Drawing.Point]::new(350, 120)
$moveTween = [TweenMoveTo]::new($monBouton, $cible, 1.2, $Script:easeElasticOut)

2. TweenColorARGB

Anime en fondu les couleurs ForeColor ou BackColor en interpolant chaque canal Alpha, Rouge, Vert et Bleu.

CONSTRUCTEUR & EXEMPLE
[TweenColorARGB]::new([Control]$pControl, [string]$pType, [Color]$pStartColor, [Color]$pEndColor, [double]$pDuration, [string]$pEasing)

# Exemple : Transitionner l'arrière-plan vers un bleu royal
$colDepart = [System.Drawing.Color]::FromArgb(255, 30, 30, 30)
$colFin    = [System.Drawing.Color]::FromArgb(255, 0, 122, 255)
$colorTween = [TweenColorARGB]::new($monLabel, "BackColor", $colDepart, $colFin, 0.8, $Script:easeQuadInOut)

3. TweenNumericString

Anime une valeur numérique textuelle dans la propriété Text d'un contrôle (compteurs, scores, jauges).

CONSTRUCTEUR & EXEMPLE
[TweenNumericString]::new([Control]$pControl, [string]$pType, [double]$pStartValue, [double]$pEndValue, [double]$pDuration, [string]$pEasing)

# Exemple : Animer un score de 0 à 1500 en 2.5s ("int" ou "double")
$numTween = [TweenNumericString]::new($lblScore, "int", 0, 1500, 2.5, $Script:easeExpoOut)

4. TweenProgressBar

Anime la propriété Value d'un composant System.Windows.Forms.ProgressBar.

CONSTRUCTEUR & EXEMPLE
[TweenProgressBar]::new([ProgressBar]$pProgressBar, [double]$pStartValue, [double]$pEndValue, [double]$pDuration, [string]$pEasing)

# Exemple : Remplir une barre de progression de 0 à 100% en 3.0s
$barTween = [TweenProgressBar]::new($progressBar1, 0, 100, 3.0, $Script:easeCubicInOut)

5. TweenOpacity

Anime en fondu la transparence globale d'une Form (Opacity bornée entre 0.0 et 1.0).

CONSTRUCTEUR & EXEMPLE
[TweenOpacity]::new([Control]$pForm, [double]$pEndValue, [double]$pDuration, [string]$pEasing)

# Exemple : Apparition progressive d'une fenêtre en 0.75s
$fadeTween = [TweenOpacity]::new($maFenetre, 1.0, 0.75, $Script:easeSineOut)

6. TweenWaiter

Minuteur non-bloquant qui exécute un ScriptBlock à la fin du temps imparti sans modifier l'interface.

CONSTRUCTEUR & EXEMPLE
[TweenWaiter]::new([System.Object]$pControl, [double]$pDuration, [scriptblock]$pCallBack)

# Exemple : Exécution différée après 2 secondes
[TweenWaiter]::new($null, 2.0, {
    [System.Windows.Forms.MessageBox]::Show("2 secondes se sont écoulées !")
})

💡 Recettes & Patterns Avancés

1. Enchaînement d'Animations Multiples (Chaining)

POWERSHELL
# Déplacement à droite, changement de couleur, puis descente avec rebond
$t1 = [TweenMoveTo]::new($btn, [System.Drawing.Point]::new(200, 50), 0.8, $Script:easeCubicOut)
$t1.setOnComplete({
    $c = [TweenColorARGB]::new($btn, "BackColor", [System.Drawing.Color]::Gray, [System.Drawing.Color]::ForestGreen, 0.5, $Script:easeLinear)
    $c.setOnComplete({
        [TweenMoveTo]::new($btn, [System.Drawing.Point]::new(200, 200), 0.8, $Script:easeBounceOut)
    })
})

2. Transmission d'Arguments Personnalisés aux Callbacks

POWERSHELL
$myTween = [TweenMoveTo]::new($panel, [System.Drawing.Point]::new(0, 0), 1.0, $Script:easeExpoOut)

$callback = {
    param($instanceTween, $messagePerso, $nouvelEtat)
    Write-Host "Terminé sur le contrôle : $($instanceTween.control.Name)"
    Write-Host "Message : $messagePerso | État : $nouvelEtat"
}

$myTween.setOnComplete($callback, @("Volet déployé", 1))

3. Animations Échelonnées (Staggering)

POWERSHELL
$cards = @($card1, $card2, $card3, $card4)
$pasDelai = 0.1

for ($i = 0; $i -lt $cards.Count; $i++) {
    $dest = [System.Drawing.Point]::new(50, 50 + ($i * 60))
    $t = [TweenMoveTo]::new($cards[$i], $dest, 0.6, $Script:easeBackOut)
    $t.setDelay($i * $pasDelai)
}

⚙️ Notes Techniques & Bonnes Pratiques

⚠️
Threading WinForms STA Les animations s'exécutent sur le thread principal de l'interface. Évitez les opérations synchrones bloquantes (comme Start-Sleep) durant les animations actives pour préserver la fluidité.

Calcul par Ticks vs Temps Réel : La durée est convertie en ticks internes (ticks = dureeEnSecondes * refreshRate). Si l'interface subit un ralentissement temporaire, les ticks sont comptabilisés séquentiellement, garantissant une arrivée exacte aux coordonnées cibles sans dépassement.
