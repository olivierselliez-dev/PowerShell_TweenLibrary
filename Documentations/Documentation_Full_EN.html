PowerShell Tween Library

A lightweight, class-based animation and tweening engine for Windows Forms in PowerShell. Implements Robert Penner's complete easing suite for smooth, non-linear transitions and dynamic desktop UI animations.

"And yes, it's quite useless but it's funny :)"

✨ Features

  • 41 Robert Penner Easing Curves: Includes all standard algorithms (Linear, Quad, Cubic, Quart, Quint, Sine, Expo, Circ, Elastic, Bounce, Back) across In, Out, InOut, and OutIn modes.
  • Pure PowerShell 5.1+ OOP: Implemented natively with PowerShell classes for high performance and clean modular structure.
  • Zero Binary Dependencies: Runs out of the box on standard .NET System.Windows.Forms and System.Drawing assemblies.
  • Comprehensive Property Coverage: Animate positions (Point), ARGB colors (ForeColor / BackColor), numeric text strings, progress bars, and form opacity.
  • Event-Driven & Sequence-Ready: Native support for start delays, pause/resume, force-finish, and completion callbacks with arbitrary argument injection.
  • Self-Managing Lifecycle: Instantiated tweens automatically register to the global engine loop and cleanly unregister upon completion.

🏛 Project Architecture

The library is modularized into four core files within the Tweens/ directory:

File Role Primary Responsibilities
TweensVariables.ps1 Constants Declares 41 script-scoped string variables (e.g. $Script:easeBounceOut).
Tweens.ps1 Data Models Defines the Tween base class and all derived animation models.
TweensUpdater.ps1 Engine & Timer Manages the central Timer, active list $Script:tweensList, and frame updates.
TweensMovement.ps1 Math & Logic Executes the core Ease mathematical function and updates control properties.

🚀 Getting Started

Prerequisites

Windows PowerShell 5.1 or PowerShell 7+ on Windows with WinForms assemblies available.

Dot-Sourcing the Modules

POWERSHELL 
# Load assemblies
Add-Type -AssemblyName System.Windows.Forms
Add-Type -AssemblyName System.Drawing

# Import the library in order
. "$PSScriptRoot\Tweens\TweensVariables.ps1"
. "$PSScriptRoot\Tweens\Tweens.ps1"
. "$PSScriptRoot\Tweens\TweensUpdater.ps1"
. "$PSScriptRoot\Tweens\TweensMovement.ps1"

Engine Lifecycle Management

POWERSHELL 
# 1. Start the animation loop when the window is shown
$mainForm.Add_Shown({ 
    $Script:tweensTimer.Start()
})

# 2. CRITICAL: Stop & Dispose the timer upon closing to prevent session memory leaks
$mainForm.Add_Closing({ 
    $Script:tweensTimer.Stop()
    $Script:tweensTimer.Dispose() 
})
💡
Customizing Frame Rate The default refresh rate is 60 FPS ($Script:refreshRate = 60 in TweensUpdater.ps1). You can customize this rate before starting the timer.

Minimal Working Example

POWERSHELL (Complete Script) 
Add-Type -AssemblyName System.Windows.Forms
Add-Type -AssemblyName System.Drawing

. "$PSScriptRoot\Tweens\TweensVariables.ps1"
. "$PSScriptRoot\Tweens\Tweens.ps1"
. "$PSScriptRoot\Tweens\TweensUpdater.ps1"
. "$PSScriptRoot\Tweens\TweensMovement.ps1"

$form = [System.Windows.Forms.Form]::new()
$form.Text = "Tween Minimal Example"
$form.Size = [System.Drawing.Size]::new(400, 300)
$form.StartPosition = "CenterScreen"

$btn = [System.Windows.Forms.Button]::new()
$btn.Text = "Click Me!"
$btn.Size = [System.Drawing.Size]::new(120, 40)
$btn.Location = [System.Drawing.Point]::new(20, 20)
$form.Controls.Add($btn)

$btn.Add_Click({
    $dest = [System.Drawing.Point]::new(220, 180)
    $t = [TweenMoveTo]::new($btn, $dest, 1.5, $Script:easeBounceOut)
    $t.setOnComplete({ $btn.Text = "Arrived!" })
})

$form.Add_Shown({ $Script:tweensTimer.Start() })
$form.Add_Closing({
    $Script:tweensTimer.Stop()
    $Script:tweensTimer.Dispose()
})

[System.Windows.Forms.Application]::Run($form)

📚 Tween Class Reference

Base Class: Tween

The abstract root class for all animations. Instantiating any derived tween automatically pushes it into $Script:tweensList.

Method Signature Description
setDelay [void] setDelay([double]$seconds) Sets a pre-animation delay in seconds.
setOnComplete [void] setOnComplete([scriptblock]$cb) Registers a callback executed when the tween ends.
setOnComplete [void] setOnComplete([scriptblock]$cb, [object[]]$args) Registers a callback with injected arguments.
pause [void] pause([bool]$isPaused) Pauses ($true) or resumes ($false) the animation.
stop [void] stop() Cancels and removes the tween from the active loop immediately.
forceEnd [void] forceEnd() Clears remaining delay and jumps to completion on the next tick.

1. TweenMoveTo

Animates 2D Location (Point(X, Y)) of any Windows Forms control.

CONSTRUCTOR & USAGE
[TweenMoveTo]::new([Control]$pControl, [System.Drawing.Point]$pDestPos, [double]$pDuration, [string]$pEasing)

# Example: Move a button to (350, 120) in 1.2 seconds
$target = [System.Drawing.Point]::new(350, 120)
$moveTween = [TweenMoveTo]::new($myButton, $target, 1.2, $Script:easeElasticOut)

2. TweenColorARGB

Transitions ForeColor or BackColor by interpolating Alpha, Red, Green, and Blue channels independently.

CONSTRUCTOR & USAGE
[TweenColorARGB]::new([Control]$pControl, [string]$pType, [Color]$pStartColor, [Color]$pEndColor, [double]$pDuration, [string]$pEasing)

# Example: Blend background color to Royal Blue
$startCol = [System.Drawing.Color]::FromArgb(255, 30, 30, 30)
$endCol   = [System.Drawing.Color]::FromArgb(255, 0, 122, 255)
$colorTween = [TweenColorARGB]::new($myLabel, "BackColor", $startCol, $endCol, 0.8, $Script:easeQuadInOut)

3. TweenNumericString

Animates numeric text values in a control's Text property (score counters, statistics).

CONSTRUCTOR & USAGE
[TweenNumericString]::new([Control]$pControl, [string]$pType, [double]$pStartValue, [double]$pEndValue, [double]$pDuration, [string]$pEasing)

# Example: Animate counter from 0 to 1500 in 2.5s ("int" or "double")
$numTween = [TweenNumericString]::new($lblScore, "int", 0, 1500, 2.5, $Script:easeExpoOut)

4. TweenProgressBar

Animates the Value property of a System.Windows.Forms.ProgressBar.

CONSTRUCTOR & USAGE
[TweenProgressBar]::new([ProgressBar]$pProgressBar, [double]$pStartValue, [double]$pEndValue, [double]$pDuration, [string]$pEasing)

# Example: Fill progress bar from 0% to 100% in 3.0s
$barTween = [TweenProgressBar]::new($progressBar1, 0, 100, 3.0, $Script:easeCubicInOut)

5. TweenOpacity

Smoothly animates a Form's transparency (Opacity clamped between 0.0 and 1.0).

CONSTRUCTOR & USAGE
[TweenOpacity]::new([Control]$pForm, [double]$pEndValue, [double]$pDuration, [string]$pEasing)

# Example: Fade in a window over 0.75s
$fadeTween = [TweenOpacity]::new($myWindow, 1.0, 0.75, $Script:easeSineOut)

6. TweenWaiter

A non-blocking delay timer that executes a callback upon completion without altering UI properties.

CONSTRUCTOR & USAGE
[TweenWaiter]::new([System.Object]$pControl, [double]$pDuration, [scriptblock]$pCallBack)

# Example: Execute after 2.0 seconds
[TweenWaiter]::new($null, 2.0, {
    [System.Windows.Forms.MessageBox]::Show("2 seconds have elapsed!")
})

💡 Advanced Recipes & Patterns

1. Chaining Multiple Animations

POWERSHELL
# Move right, change color, then bounce down
$t1 = [TweenMoveTo]::new($btn, [System.Drawing.Point]::new(200, 50), 0.8, $Script:easeCubicOut)
$t1.setOnComplete({
    $c = [TweenColorARGB]::new($btn, "BackColor", [System.Drawing.Color]::Gray, [System.Drawing.Color]::ForestGreen, 0.5, $Script:easeLinear)
    $c.setOnComplete({
        [TweenMoveTo]::new($btn, [System.Drawing.Point]::new(200, 200), 0.8, $Script:easeBounceOut)
    })
})

2. Injecting Custom Arguments into Callbacks

POWERSHELL
$myTween = [TweenMoveTo]::new($panel, [System.Drawing.Point]::new(0, 0), 1.0, $Script:easeExpoOut)

$callback = {
    param($tweenInstance, $customMsg, $nextState)
    Write-Host "Finished on control: $($tweenInstance.control.Name)"
    Write-Host "Message: $customMsg | State: $nextState"
}

$myTween.setOnComplete($callback, @("Drawer Opened", 1))

3. Staggered Animations

POWERSHELL
$cards = @($card1, $card2, $card3, $card4)
$delayStep = 0.1

for ($i = 0; $i -lt $cards.Count; $i++) {
    $dest = [System.Drawing.Point]::new(50, 50 + ($i * 60))
    $t = [TweenMoveTo]::new($cards[$i], $dest, 0.6, $Script:easeBackOut)
    $t.setDelay($i * $delayStep)
}

⚙️ Technical Notes & Best Practices

⚠️
WinForms STA Threading Animations execute on the main UI thread. Avoid blocking synchronous operations (such as Start-Sleep) during active tweens to prevent frame stutter.

Tick vs Real Time: Duration is converted into internal ticks (ticks = durationInSeconds * refreshRate). If the UI is momentarily busy, ticks are counted sequentially, ensuring elements always land precisely at their target without skipping.
